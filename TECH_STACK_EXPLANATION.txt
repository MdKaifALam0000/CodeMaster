# CodeMaster - Comprehensive Tech Stack Report

This document details every technology, framework, and micro-library utilized in the CodeMaster project, explaining exactly *why* it was chosen and what role it plays in the overall architecture.

---

## 🎨 Frontend Stack (React / Vite)

### 1. Core Framework & Build Engine
*   **React (`react`, `react-dom`, `react-router`):** The core UI library used to build the single-page application (SPA). It manages the component lifecycle, virtual DOM updates, and client-side routing across different pages (Dashboard, Problem Page, Lobby).
*   **Vite (`vite`, `@vitejs/plugin-react`):** A next-generation build tool that replaces Webpack/Create-React-App. It provides blazing-fast Hot Module Replacement (HMR) during development and highly optimized rollup bundling for production.

### 2. State Management & Data Fetching
*   **Redux Toolkit (`@reduxjs/toolkit`, `react-redux`):** Handles complex global state management. It is primarily used to manage user authentication sessions and the real-time state of the Team Coding rooms (participants, chat history, live code).
*   **Axios (`axios`):** A promise-based HTTP client used to make REST API requests to the Node.js backend (e.g., fetching problems, submitting code, logging in).

### 3. Styling & UI Components
*   **Tailwind CSS (`tailwindcss`, `@tailwindcss/vite`):** A utility-first CSS framework used for rapid, responsive UI development without leaving the JSX files.
*   **DaisyUI (`daisyui`):** A highly customizable component library built on top of Tailwind CSS. It provides pre-built, semantic components (buttons, modals, cards, tabs) that strictly adhere to our design system.
*   **Lucide React (`lucide-react`) & React Icons (`react-icons`):** Lightweight libraries providing scalable vector graphics (SVG) icons used throughout the dashboard and user interface.

### 4. Interactive Coding Environment
*   **Monaco Editor (`@monaco-editor/react`):** This is the exact engine that powers Microsoft's VS Code. It is embedded directly into the browser to provide a professional-grade IDE experience, complete with syntax highlighting, auto-indentation, and line numbering.

### 5. Real-time Communication
*   **Socket.IO Client (`socket.io-client`):** Establishes a persistent, bi-directional WebSocket connection with the backend. It powers the Team Coding feature by broadcasting live code changes, tracking cursor movements, and handling the live chat.

### 6. Animations & Advanced Visualizations
*   **Framer Motion (`framer-motion`):** A powerful animation library used for route transitions, micro-interactions, and most importantly, driving the chronological DOM animations in the AI Algorithm Visualizer.
*   **Three.js Ecosystem (`three`, `@react-three/fiber`, `@react-three/drei`):** Used to render complex 3D graphics and data structures directly on an HTML canvas, allowing for advanced spatial visualizations of algorithms.
*   **Recharts (`recharts`):** A composable charting library built on React components. It is used in the personalized dashboard to render statistical progress graphs (pie charts, bar charts of topic mastery).

### 7. Form Handling & Validation
*   **React Hook Form (`react-hook-form`):** An extremely performant library for managing complex form states (login, signup, admin uploads) without triggering excessive re-renders.
*   **Zod (`zod`, `@hookform/resolvers`):** A TypeScript-first schema declaration library used for strict client-side validation (e.g., ensuring passwords meet complexity requirements before hitting the server).

### 8. Media & Output Processing
*   **Remotion (`remotion`, `@remotion/player`):** A programmatic video rendering library used to play and manage the AI-generated educational algorithm videos directly in the browser using React components.
*   **Google Model Viewer (`@google/model-viewer`):** A web component that allows for the interactive display of 3D models.
*   **React Markdown (`react-markdown`):** Used to safely parse and render the Markdown structured text generated by the AI Code Reviewer into formatted HTML.

### 9. Utilities
*   **React Hot Toast (`react-hot-toast`):** Provides sleek, non-blocking toast notifications for success/error alerts.
*   **js-cookie (`js-cookie`):** A simple API for handling browser cookies natively in JavaScript.

## ⚙️ Backend Stack (Node.js / Express)

### 1. Core Framework
*   **Node.js & Express.js (`express`):** The core runtime environment and minimalist web framework. It handles the RESTful API routing, middleware execution, and HTTP request/response lifecycles.

### 2. Database & Caching Layer
*   **MongoDB (`mongoose`):** The primary NoSQL database. Mongoose is used as an Object Data Modeling (ODM) library to enforce strict schemas for Users, Problems, Test Cases, and Team Rooms.
*   **Redis (`redis`):** An ultra-fast, in-memory data structure store. It acts as a caching layer to temporarily store heavily requested data (like problem descriptions or leaderboards), massively reducing the load on MongoDB.

### 3. Security & Authentication
*   **JSON Web Tokens (`jsonwebtoken`):** Used for stateless, secure user authentication. Tokens are signed and stored in HTTP-only cookies to prevent XSS attacks.
*   **Bcrypt (`bcrypt`):** A cryptographic library used to securely salt and hash user passwords before they are ever saved to the database.
*   **Express Rate Limit (`express-rate-limit`):** A security middleware that throttles incoming requests from the same IP address, protecting the API from brute-force login attacks and DDoS attempts.
*   **CORS (`cors`):** Middleware that securely manages Cross-Origin Resource Sharing, ensuring the API only accepts requests from the allowed Vite frontend.
*   **Cookie Parser (`cookie-parser`):** Middleware used to easily extract and parse the HTTP-only cookies containing the JWT during authentication.
*   **Validator (`validator`):** A library of string validators and sanitizers to prevent SQL/NoSQL injection and ensure clean data (e.g., valid email formats).

### 4. Real-time Infrastructure
*   **Socket.IO (`socket.io`):** The server-side counterpart to the frontend WebSocket client. It manages isolated "rooms", handles the Last-Write-Wins logic for code synchronization, and broadcasts messages efficiently.

### 5. Generative AI Integrations
*   **Axios (`axios`):** Used on the backend to directly interface with the OpenRouter API, specifically piping requests to the `google/gemini-2.0-flash-lite-preview-02-05:free` model.
*   **Google GenAI (`@google/genai`):** The original SDK used for integrating Google's Gemini models (kept as a dependency for legacy/fallback support).

### 6. Email & OTP Verification
*   **Nodemailer (`nodemailer`):** The core module used to construct and send transactional emails (like password reset links and account verification codes).
*   **SendGrid (`@sendgrid/mail`) & Resend (`resend`):** Professional email delivery services integrated to ensure OTP emails hit the user's inbox and not their spam folder.
*   **OTP Generator (`otp-generator`):** A utility used to securely generate random, numeric One-Time Passwords for the email verification flow.

### 7. Cloud Storage
*   **Cloudinary (`cloudinary`):** A cloud-based media management service. The backend uses this SDK to securely upload, optimize, and serve video tutorials and image assets uploaded by the Admin.

### 8. Backend Utilities
*   **Dotenv (`dotenv`):** Loads secret configuration variables (API keys, database URIs) from a hidden `.env` file into `process.env`.
*   **Nanoid (`nanoid`):** A tiny, secure URL-friendly unique string ID generator. Used instead of UUIDs to generate short, clean invite links for Team Coding rooms (e.g., `/room/xY8zB`).
*   **Nodemon (`nodemon`):** A development utility that monitors the file system and automatically restarts the Node server whenever code changes are saved, speeding up the development process.
